# Lesson 0.11: Show and Tell (Stage 0 Checkpoint)

**Time:** 45–60 min · **You need:** the computer, the dot cards, the cipher
wheel, cups, the floor grid (or a paper one), the passport · **New words:**
none, it's celebration day!

## Goal *(read this to the learner)*

> You've learned the big secrets of computers. Today you show them off.
> Pass the checkpoint, and you earn your first badge: **Computer
> Whisperer**!

## Before the lesson *(guide, 10 min)*

- [ ] Gather everything from Stage 0.
- [ ] Invite an audience if you can: a grandparent, a sibling, a video
      call. Explaining to someone else is the best test of understanding.
- [ ] Print the [passport](../../PASSPORT.md) if you haven't already.

## Activity: the checkpoint stations

Set up stations around the room. The learner explains and demonstrates
each one to the audience. **Don't help.** If they get stuck at a
station, note it and move on; you can come back to it another day.

1. **Station: Log in.** Log in, open GCompris, minimise it, open the
   Files app, go into `lab`, make a folder called `checkpoint`, and log
   out.
2. **Station: Save a file.** Log back in. Open the text editor, write
   "I am a Computer Whisperer", and save it as
   `lab/checkpoint/badge.txt`. Find it again in Files.
3. **Station: Binary.** Show 13 with the dot cards *(8 + 4 + 1)*, and
   write it in binary *(01101)*. Then turn `10110` back into a normal
   number *(22)*.
4. **Station: Robot program.** Write an arrow-card program to reach the
   treasure. Then find the bug in one you've planted.
5. **Station: The five jobs.** Point to an input, an output, and where
   the processor, memory and storage are.
6. **Station: Secret message.** Decrypt `FRPSXWHU` with key 3
   *(COMPUTER)*.
7. **Station: Home row.** Fingers on the home row, eyes closed, and type
   `asdf jkl;`.

## Afterwards

- Sign and date the passport. Stamp it, or add a sticker.
- Tell them what's next: "Next, you'll learn to talk to the computer
  with *no mouse at all*, just typing commands, like a real hacker. It's
  called **the terminal**."

## If a station didn't go well

That's fine, and it's what checkpoints are for. Go back to that
station's lesson (see the table below), do it again on another day, and
then retry just that station. Keep typing practice going in free play
in the meantime.

| Station | Lesson to revisit |
|---|---|
| Log in, Save a file | 0.4, 0.5 |
| Binary | 0.6 |
| Robot program | 0.1, 0.9 |
| The five jobs | 0.2 |
| Secret message | 0.10 |
| Home row | 0.3 (plus more free play) |
